# Projekt-Cockpit

Projektmanagement-Cockpit mit Projekten, Benutzern & Login, Rollen und Rechten, digitalem Projekthandbuch (pma), Kanban-Board mit Drag & Drop und Terminplan.

Live: https://lucakofler1.github.io/ProjektCockpit/

*Cockpit von Luca Kofler*

## Online-Datenbank (Supabase)
1. `supabase-setup.sql` einmal im Supabase SQL Editor ausführen.
2. In Supabase unter Authentication → Email „Confirm email“ ausschalten.
3. Project URL + öffentlichen Key oben in `index.html` (SUPABASE_URL / SUPABASE_KEY) eintragen.
